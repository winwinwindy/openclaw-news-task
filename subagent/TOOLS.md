## 📰 新闻校验 Agent (news-validator)

**重要：在邮件发送前必须触发校验，校验失败则调整，成功后再发送**

### 工作流顺序
```
1. financial-news-scraper → 爬取新闻
2. news-site-generator  → 生成网站
3. subagent 校验      → 检查质量（邮件发送前）
   - FAIL → 调整新闻数据，重新生成网站，再次校验
   - PASS → 继续下一步
4. 发送邮件         → 校验通过后才发送
5. 记录结果        → 记录到 memory
```

- 标题不能为空

### 中英文切换功能详细校验（必须检查！）

请读取 news-site/index.html 文件，验证以下功能：

1. **切换按钮存在性**
   - 检查 HTML 中是否有切换按钮（class 含 "lang-btn" 或类似）
   - 确认有"中"和"ENG"两个按钮

2. **按钮高亮逻辑**
   - 检查 JavaScript 中 setLang 函数是否正确切换按钮的 active 状态
   - 确认点击后按钮 class 包含 "active"

3. **内容切换完整性**
   - 检查 translations 对象是否包含完整双语数据
   - 检查 setLang 函数是否更新以下内容：
     - 页面标题 (.title)
     - 日期 (.date)
     - 市场指数名称 (.ticker-name)
     - 新闻标题 (.news-card-title)
     - 新闻摘要 (.news-card-summary)
     - 新闻来源 (.news-source)

4. **数据属性检查**
   - 每条新闻必须有以下 data 属性：
     - data-title-zh + data-title-en
     - data-summary-zh + data-summary-en
     - data-source-zh + data-source-en
   - 每个指数必须有：
     - data-name-zh + data-name-en

5. **指数颜色检查**
   - CSS 中 .positive 类使用红色 (#f85149 或 #ff4444)
   - CSS 中 .negative 类使用绿色 (#3fb950 或 #00c851)

6. **时间格式检查**
   - 所有新闻时间必须符合格式：YYYY-MM-DD HH:MM
   - 例如：2026-04-03 14:00
   - 不能使用"刚刚"、"3小时前"、"昨天"等相对时间

7. **新闻字段完整性检查**
   - 每条新闻必须包含：
     - 标题 (a href 链接)
     - 摘要 (p 标签内容)
     - 发布时间 (时间戳)
     - 来源 (路透社/彭博等)
     - 跳转链接 (完整的 URL，不是首页)

### 根据结果处理（循环直到通过）

| 校验结果 | 处理方式 |
|----------|----------|
| PASS | 继续发送邮件，记录到 memory |
| FAIL | 解析失败原因，调整后重新校验（最多3次） |

**失败重试逻辑**：
1. 链接无效 → 重新爬取，获取有效链接
2. 时效性不足 → 重新爬取最新新闻
3. 指数颜色错误 → 调整CSS颜色（上涨红/下跌绿）
4. 内容不准确 → 重新生成新闻项
5. 邮件样式错误 → 调整模板后重新发送
6. 时间格式错误 → 修正为 年-月-日 时：分 格式
7. 新闻字段缺失 → 补充完整字段（标题+摘要+时间+来源+链接）
