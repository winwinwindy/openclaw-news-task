# 金融新闻爬取

## 支持的新闻源

| 网站 | URL | 语言 |
|------|-----|------|
| 路透社 | https://www.reuters.com/ | 英语 |
| 金融时报 | https://www.ft.com/ | 英语 |
| 彭博新闻 | https://www.bloomberg.com/ | 英语 |
| 财新网 | https://www.caixin.com/ | 中文 |
| 华尔街见闻 | https://wallstreetcn.com/ | 中文 |

## 爬取流程

### 1. 使用 Browser 工具打开目标网站

使用 `browser` 工具的 `open` action 打开网页：
```
browser({ action: "open", targetUrl: "https://www.reuters.com/" })
```

### 2. 获取页面快照

使用 `browser` 工具的 `snapshot` action 获取页面结构：
```
browser({ action: "snapshot", targetId: "<targetId>" })
```

### 3. 解析新闻数据

从页面 DOM 结构中提取：
- 新闻标题 (heading 或 link 文本)
- 新闻摘要 (paragraph 或 description)
- 发布时间 (time 标签或相对时间)
- 来源网站 (从 URL 域名提取)
- 原文网址 (link 的 href 属性)

### 4. 多源覆盖策略（关键）

**必须遍历所有支持的新闻源，确保多源覆盖：**

1. **优先级顺序**：Reuters → Bloomberg → FT → 财新 → 华尔街见闻
2. **每网站获取 3-5 条新闻**，确保总数量达到 10 条以上
3. **如果某网站获取失败**，记录错误并继续尝试下一个网站
4. **最终结果中来源分布应该多元化**，避免单一来源

**多源验证：**
- 每条新闻必须标注来源网站
- 生成的 HTML 中应显示不同来源的新闻
- 如果某来源获取失败，需要在日志中记录

### 5. 格式化输出

将爬取的新闻整理为以下格式：

```
## [网站名称] 热点新闻

| # | 标题 | 摘要 | 发布时间 | 来源 |
|---|------|------|----------|------|
| 1 | xxx | xxx | xxx | xxx |
```

## 注意事项

- 路透社、金融时报、彭博可能需要处理广告和登录墙，尽量选择公开可见的文章
- 财新网和华尔街见闻有中文界面，注意编码
- 优先获取头条和最新新闻区域的内容
- 每网站建议获取 5-10 条热门新闻
- 如果某网站无法访问，记录错误并继续尝试其他网站
